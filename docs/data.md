# Datasets (India only)

Large files are not committed (`data/` is git-ignored). Scripts live in `scripts/training/`; the full runbook is
[ml/retraining.md](ml/retraining.md).

```text
data/
├── rdd2022_india/     # official RDD2022 India train set: images + Pascal VOC XML (source of truth)
├── road_v2/           # YOLO labels converted from that XML, by class NAME (train/val/test)
├── Crack dataset/     # road-pavement crack masks only (for the crack-outline model)
├── india_extra/       # optional extra Indian data, one folder per source (YOLO export)
└── build/             # generated by the build scripts (safe to delete and rebuild)
```

## Road damage detection — `road_v2`

```bash
python scripts/training/fetch_rdd2022_india.py --out data/rdd2022_india   # ~425 MB, India only
python -I scripts/training/convert_rdd_xml.py                              # -> data/road_v2
```

Source: RDD2022 released through CRDDC'2022, figshare DOI 10.6084/m9.figshare.21431547,
CC BY-SA 4.0 (attribution + share-alike apply to derived datasets).

| Class | train | val | test |
|---|---|---|---|
| D00 longitudinal crack | 1,103 | 223 | 229 |
| D10 transverse crack | 50 | 11 | 7 |
| D20 alligator crack | 1,428 | 307 | 286 |
| D40 pothole | 2,236 | 506 | 445 |

Dropped by name: D44 white-line blur (1,062), D01 (179), D43 crosswalk blur (57),
D11 (45), D50 manhole (28), D0w0 (1).

**History:** the earlier `data/road` copy (from the shared `RDD_SPLIT`) lumped all of
those dropped classes into class 3 "pothole" and lost every real pothole — the
current production model learnt "faded paint = pothole" from it. It was deleted on
2026-11-21 (a copy remains in `Downloads/road.zip`).

## Crack outlines — `Crack dataset`

Kept only road-pavement sources: CRACK500, GAPS384, CrackTree200, CFD, CrackForest,
AEL. Wall / concrete / stock-photo sources (Rissbilder, Volker, Eugen, noncrack,
DeepCrack — 6,799 images) were deleted on 2026-11-21 (a copy remains in
`Downloads/road.zip`). Build the segmentation set with
`python scripts/training/build_crack_seg.py` (adds 500 crack-free Indian road crops).

Class IDs stay Flask-compatible: D00 / D10 / D20 / D40.
